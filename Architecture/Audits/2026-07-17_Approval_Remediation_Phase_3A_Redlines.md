## 2. Selected storage and authority design

Phase 3A selects Pattern A: one physical SQLite database at `%LOCALAPPDATA%\RandleRuntimeData\control\runtime_authority_v1.sqlite3`. Ownership-separated tables retain named logical writers. A Runtime Authority Store Transaction Coordinator owns only the physical connection, transaction serialization, fsync/readback, and table-writer authorization; it cannot originate, evaluate, grant, or own any domain identity or transition. Same-database foreign keys are enforceable. External stores and projections cannot duplicate or restore authority.
